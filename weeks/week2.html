📌 第 5 讲 应用题（归类 + 改错）

(a)字段归类 （8 分）
将以下 8 个字段分别归入 EnvCfg 或 RLCfg（每侧至少 3 个）：

(b)找错 （7 分）
执行下面的代码，会发生什么？请说明原因（提示：结合 hasattr 检查）。
env = registry.make(
    name="my-env",
    sim_backend="np",
    num_envs=256,
    env_cfg_override={"not_exist_param": 2.0},
)
回答内容：
会抛出 ValueError，环境创建失败。原因：registry.make() 处理 env_cfg_override 时，会对每个 key 做 hasattr(env_cfg, key) 检查；not_exist_param 不是配置类的属性，hasattr 判否后直接 raise ValueError("Config class '...' has no attribute 'not_exist_param'")——既不会静默忽略，也不会自动补属性。正确做法：把 key 换成配置类中真实存在的字段名。

回答内容： 
import os
from dataclasses import dataclass

from motrix_envs import registry
from motrix_envs.base import EnvCfg

model_file = os.path.dirname(__file__) + "/simple_walker.xml"


@registry.envcfg("simple_walker")          # 以环境名为 key 注册 EnvCfg 子类
@dataclass
class SimpleWalkerEnvCfg(EnvCfg):
    # 机器人模型文件路径（MJCF 资产），EnvCfg 基类字段
    model_file: str = model_file
    # reset 时关节初始位置噪声幅度：打破同批次环境初态完全一致，提升鲁棒性
    reset_noise_scale: float = 0.01
    # 单条 episode 最长秒数：超时终止（timeout），基类据此换算 max_episode_steps
    max_episode_seconds: float = 20
    # 渲染模式下相邻并行环境的间距，只影响可视化、不影响训练
    render_spacing: float = 2.0
(b)环境实现 （8 分）simple_walker_np.py
写出装饰器的完整写法（含环境名与仿真后端），并列出必须实现的三个抽象方法名。
